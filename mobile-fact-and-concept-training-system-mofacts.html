Adaptive practice

MoFaCTS

What it does

MoFaCTS supports research on how practice should be selected, scheduled, and adapted across different kinds of learning content. Use MoFaCTS for adaptive practice when suitable lesson content and access are available, or use the open-source code for a research deployment.

A skinned MoFaCTS implementation also supports adaptive video learning through Cognivideo.

The MoFaCTS codebase is available under the GNU Affero General Public License version 3 (AGPL-3.0-only).

Open MoFaCTS MoFaCTS GitHub Cognivideo

Why it matters

  • Supports adaptive practice experiments
  • Tracks learner interaction history over time
  • Connects theory to implementation and reporting

Learner modeling

LKT

What it does

Logistic Knowledge Tracing (LKT) is an R package for building and comparing interpretable models of learner performance. Researchers can combine features of practice history, success, failure, and timing to test theories and predict subsequent performance. Install LKT from CRAN and explore the tutorial to use it with your own data. MoFaCTS users are invited to explore LKT for learner modeling and analysis of practice histories.

LKT on CRAN LKT on GitHub LKT tutorial

Why it matters

  • Supports modeling and feature-based analysis
  • Provides reusable package-level methods and documentation
  • Complements the platform side of the lab's software work

New research innovation

TutorScript and SPARC

What it does

SPARC (Semantic Pages with Adaptive Rules and Cognition) is an emerging tutoring system within MoFaCTS. TutorScript is its language for expressing explicit instructional rules; the two names refer to the system and its rule language, respectively.

Learner models estimate knowledge from response evidence. TutorScript rules specify which instructional actions are eligible and how an action is selected. Generative AI then realizes the selected action as an explanation, worked example, teaching figure, or question. Separating instructional choice from language generation makes the choices available for inspection and experimental study.

Explore TutorScriptInstructional-cycle infographic

Research and availability

Current research implementations support both rule-guided agent selection and student choice among instructional moves. Local browser acceptance checks have exercised these paths and saved decision histories.

These observations establish research capabilities in controlled deployments. The newer dynamic instruction policies remain restricted to administrator research use; they are not a general public feature. The wiki describes the current scope and technical details.
