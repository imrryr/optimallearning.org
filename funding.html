NSF | 08/01/2023 - 07/31/2027

Improving STEM K-12 Learning Using Optimal Spaced Retrieval in an Existing Educational Technology Platform

This project focuses on creating a smarter study and review tool for STEM learning that helps students remember science and mathematics content over time by using adaptive spaced retrieval inside an existing educational technology platform.

K-12 STEM learning Spaced retrieval Educational technology
IES | 07/01/2019 - 06/30/2022

Adaptive Practice in Postsecondary Anatomy and Physiology

This project examined how adaptive practice could improve recall and understanding in a demanding postsecondary domain. It represents applied work on bringing model-based scheduling into authentic educational settings.

Applied learning research Postsecondary instruction Adaptive practice
NSF | 01/01/2015 - 12/31/2019

Scalable Infrastructure for Data-Driven Discovery and Innovation in Education

This work supported infrastructure for educational data analysis and contributed to the LKT package and related methodological resources available on this site.

Learning analytics Infrastructure LKT
IES | 07/01/2007 - 06/30/2012

Bridging the Bridge to Algebra

This grant focused on improving pre-algebra learning by identifying and supporting prerequisite skills through an automated instructional intervention.
