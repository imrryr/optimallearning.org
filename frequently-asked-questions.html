FAQ

Common questions about use, scheduling, and adaptive practice.

Common questions about using the lab's methods, software, and scheduling approach.

Use

How can these methods be used?

Individual use

People can engage with adaptive practice through MoFaCTS when suitable content and access are available.

Course or project use

Instructors and collaborators may be able to use the platform or related methods in instructional or research contexts, depending on project fit and available support.

Code and development

The site points to the GitHub repository for the MoFaCTS codebase, which is licensed under the Business Source License 1.1 (BUSL 1.1).

Research collaboration

The lab's methods can support collaborations when there is shared interest in adaptive practice, learning models, or educational software.

Scheduling

How does the system decide what is optimal?

The scheduling approach uses a mathematical model of learning to estimate when new practice should occur if later recall or performance is the goal. In broad terms, the model can take into account prior practice timing, the number of prior opportunities, spacing, success and failure history, practice type, and relationships among items.

Progression

When are new items introduced?

New material is introduced when previously introduced items appear sufficiently stable under the system's criteria. If earlier items show evidence of slipping below that threshold, the system can prioritize review instead of pushing forward immediately.
